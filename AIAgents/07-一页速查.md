## 派活前

- [ ] **说得清**：三句话能讲明白要什么、不要什么
- [ ] **验得了**：知道什么样算完成，能逐条打勾
- [ ] **退得回**：有备份或版本管理
- [ ] **权限定了**：只读还是可写，危险操作要不要二次确认
- [ ] **规模收了**：第一次做，控制在十分钟能验完的范围

三条里缺"验得了"，先补验收标准；缺"退得回"，先备份或只给只读。判断依据见 [03 篇](./03-什么活该交给它.md)。

---

## 派活时

五段不能少：

```
目标：把【什么】变成【什么】，交付到【哪里】
输入：哪几份是准的；哪几份不要用
约束：不要改什么；输出什么格式；上限多少
验收：满足哪几条算完成
停止：遇到什么情况先来问我
```

拆解粒度：**一步做完，三十秒内能判断对错**，就是合适的粒度。

---

## 派活后

四查不能省：

| 查什么 | 一句话 |
| --- | --- |
| 查范围 | 只动了该动的吗 |
| 查内容 | 逐条对验收条件 |
| 查副作用 | 别处有没有被改坏 |
| 查可复现 | 同样输入再跑一次，结论一致吗 |

出现这三种情况立刻停：**动错东西、同一招试三次、要做不可逆操作**。

---

## 三条红线

**不可逆的操作人来点、对外的发送人来发、专业结论人来签。**
