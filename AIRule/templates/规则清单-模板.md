# 规则清单-模板

> **用途**：写完规则后对着过一遍；也可以当"每周体检表"定期用
> **怎么用**：打印出来，或用的时候复制一份，逐项打勾
> **配套阅读**：[07 常见错误](../docs/07-常见错误.md) ｜ [04 怎么写一条规则](../docs/04-怎么写一条规则.md)
> **配套模板**：[RULE-模板](./RULE-模板.md)

# 一、写完自检（9 项）

*四个以上打不了勾，回去改。*

| # | 检查项 | 怎么查 | ☐ |
| --- | --- | --- | --- |
| 1 | 每条都能一眼判断"违反了没有" | 随便挑三条，想象"它违反了"长什么样。想不出来 = 写虚了 | ☐ |
| 2 | 没有形容词 | 搜"专业、简洁、自然、适当、尽量、酌情、视情况" | ☐ |
| 3 | 每条禁令都配了替代动作 | 逐条看有没有"缺东西就…" | ☐ |
| 4 | 总条数在 15 条以内 | 数 | ☐ |
| 5 | 没有步骤描述 | 搜"第一步、然后、接着、最后" | ☐ |
| 6 | 有"拿不准怎么办"这一节 | 看第三节在不在，且是具体列举 | ☐ |
| 7 | 例外写的是具体条件 | 搜"特殊情况""酌情"，有就改 | ☐ |
| 8 | 放对了位置并且验过 | 新开对话问它"你现在遵守哪些规则" | ☐ |
| 9 | 每条都是最近真的被坑过的 | 逐条回想：上个月发生过吗 | ☐ |

# 二、常见错句改写表

*左边这类句子，几乎人人都写过。右边是改法。*

| ❌ 如果你写成了这样 | ✅ 改成这样 |
| --- | --- |
| 回答要专业 | 不用"我觉得""可能吧""应该是"；不确定就写"我不确定" |
| 不要编造内容 | 数字、日期、人名必须有出处；没有就写【待确认】，并说明该找谁要 |
| 改的时候小心点 | 只改我标出来的段落。发现别处有问题，列清单告诉我，不顺手改 |
| 格式要统一 | 标题用"一、二、三"，不用"1. 2. 3."；正文不用加粗 |
| 尽量简短 | 每段不超过 4 行；结论放第一句；不写总结段 |
| 别太机械 | 不用"首先/其次/最后"开头；不用"综上所述" |
| 注意保密 | 不在回复里出现手机号、身份证号、住址；需要引用时只写后四位 |
| 有问题问我 | 遇到这三种先问我：要删文件、要外发内容、要花钱 |
| 中文回答 | 用中文回复；技术名词保留英文原词，不硬译 |
| 别乱改我的稿子 | 不许改标题、不许调段落顺序、不许换我的用词（错别字除外） |
| 写得有深度一点 | 每个结论后面跟一个具体例子或数据；没有就说明"暂无案例" |
| 语气友好一点 | 不用感叹号；每段至少有一句是直接回答，不绕 |
| 结构清晰一点 | 用小标题分节，每节不超过 3 段 |
| 别太啰嗦 | 删掉所有"总的来说""值得注意的是""需要指出的是" |
| 表格好看一点 | 表头加粗、冻结首行；金额右对齐；不合并单元格 |

**改写的通用公式**：把形容词换成一个**能数、能查、能列举**的东西。

# 三、每周体检（5 分钟）

*固定一周一次，比写完不管强十倍。*

| 问题 | 答案 | 动作 |
| --- | --- | --- |
| 这周有哪条规则被违反了？ | | 违反了 1 次 → 观察；2 次 → 改具体；3 次 → 说明缺这条，补上 |
| 有哪条从来没触发过？ | | 连续三个月没触发 → 删 |
| 我这周有没有口头补过什么要求？ | | 有 → 那句话本该在文件里，补进去 |
| 有两条规则打架了吗？ | | 有 → 按"红线优先 → 近的优先"处理，或拆层 |
| 规则文件和实际做法一致吗？ | | 不一致 → 要么改规则，要么改做法，别拖着 |

---

# 四、每季度大扫除（10 分钟）

| # | 动作 | ☐ |
| --- | --- | --- |
| 1 | 逐条问"现在还对吗"，过期产品名、已停的业务全删 | ☐ |
| 2 | 逐条问"这条现在该在哪一层"，项目专用的下沉，通用的上提 | ☐ |
| 3 | 合并重复的条目（同一条规矩写了两遍的） | ☐ |
| 4 | 更新"生效与修改"的日期与原因 | ☐ |
| 5 | 数一下总条数，超过 15 条就砍 | ☐ |

---

# 五、给别人用之前的检查（4 项）

| # | 检查项 | ☐ |
| --- | --- | --- |
| 1 | 删掉了只跟我有关的内容（我的路径、我的偏好、我的项目代号） | ☐ |
| 2 | 写清了"这份规则假设了什么"（比如"假设你在做中文内容"） | ☐ |
| 3 | 附了一句怎么用（放哪个目录、要不要开新对话） | ☐ |
| 4 | 自己先用了一周，确认它真的有用 | ☐ |

---

## 一句话记住

**规则不是写完就完了，是每三个月都要删掉几条的东西。**

能删得掉，说明你在维护；一条都舍不得删，说明你根本没在用。
