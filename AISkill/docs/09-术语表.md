## 9.1 术语对照表

| 术语 | 大白话解释 | 生活里的比方 |
| --- | --- | --- |
| AI / 大模型 | 能对话、能写东西的程序 | 知识很广但刚入职的实习生 |
| 提示词（Prompt） | 你对 AI 说的那段话 | 点菜时说的话 |
| 上下文 / 上下文窗口 | AI 一次能同时"看见"的字数上限 | 桌面上能摊开的纸的量 |
| 技能（Skill） | 一套固定的做事步骤 | 泡面包装上的冲泡步骤 |
| AISkill | 写成文件、交给 AI 执行的技能 | 给实习生的岗位操作手册 |
| 元信息（Metadata） | 关于这份文件的说明：名字、版本、什么时候用 | 书的封面和目录 |
| 指令正文 | 真正给 AI 看的那份操作步骤 | 手册的正文部分 |
| .md / Markdown | 一种带简单标记的纯文字文件 | 用符号做批注的稿纸 |
| 路径 | 文件在电脑里的门牌地址 | 北京市朝阳区XX路1号 |
| 绝对路径 | 从头写全的地址 | 快递能直接送到的完整地址 |
| 相对路径 | 从当前位置算起的地址 | "隔壁302" |

## 9.2 容易混淆的三组词

**技能 vs AISkill**
"技能"是那套做法本身，存在人脑子里；"AISkill"是把它写下来、存成文件。前者是想法，后者是文件。

**绝对路径 vs 相对路径**
绝对路径像"北京市朝阳区XX路1号"，走哪都能找到；相对路径像"隔壁302"，只在当前这栋楼里成立，但整栋楼搬走它还是对的。**写手册用相对路径。**

**提交 vs 推送**
提交是"在本地拍张快照"，推送是"把快照传到网上"。只提交不推送，别人看不到；只推送不提交，什么都没发生。

## 9.3 本手册自己的文件名词

读这套文档时还会遇到几个词，一并说明。

| 词 | 指什么 |
| --- | --- |
| 分册 / 一篇 | `docs/` 下的一个 `.md` 文件 |
| 入口 | `README.md`，所有阅读从这里开始 |
| 模板 | `templates/` 下的空白骨架，复制后填空 |
| 本节 / 本篇 | 指你正在读的这个文件 |
| 上一篇 / 下一篇 | 按学习顺序相邻的文件，在每篇结尾 |

## 怎么用这张表

- **读正文卡住时**：回来搜关键词，看一眼比方就懂了，不用通读。
- **写手册时**：想用某个词，先确认这里的解释和你理解的一致，避免自创说法。
- **给同事讲时**：直接用这里的比方，比自己解释省力。
