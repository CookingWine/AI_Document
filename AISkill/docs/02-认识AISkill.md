这一篇讲一件很朴素的事：AISkill 到底是个什么东西。看完你就知道，它不需要代码，也不是什么高深技术——它就是一两个写好的文本文件。

---

## 2.1 先看一个最小的例子

假设你每周都要写周报，每次都要跟 AI 解释半天。把它做成技能，只需要一个文件，内容大概是这样：

```
# 周报生成

## 什么时候用
用户说"写周报""本周总结""周报模板"时。

## 我是谁
电商公司客服主管，团队 5 人。

## 怎么做
1. 先问用户要三个数据：本周咨询量、主要问题、下周重点。
2. 按"本周数据 / 主要问题 / 下周计划"三段写。
3. 每段不超过 100 字，语气正式，不用感叹号。
4. 如果用户没给数据，先用【待补充】占位，不要编造数字。

## 不要做什么
- 不要写"感谢领导"之类的客套话。
- 不要自己编造没提供的数字。
```

就这些。不需要代码，不需要特殊软件。

**注意最后一段**。"不要做什么"往往比"要做什么"更重要——AI 犯的错，八成是你不想要但它觉得"顺手"就加上的东西。

> 💡 **想直接动手**
> 这份例子的空白版本在 [SKILL-模板](../templates/SKILL-模板.md)，复制过去逐项填就行。

## 2.2 一个完整的 AISkill 里有什么

做得更正式一些，会有下面这些部分。**不是每个都必须有**，从简单的开始即可。

| 部分 | 大白话解释 | 必须吗 |
| --- | --- | --- |
| 名称 | 这个技能叫什么，一句话能看懂 | 必须 |
| 适用场景 | 什么情况下该用它 | 必须 |
| 步骤 | 具体怎么做，一步一步 | 必须 |
| 禁止事项 | 明确不许做什么 | 强烈建议 |
| 示例 | 给一组"输入 → 输出"的样例 | 强烈建议 |
| 参考资料 | 术语表、模板、长文档 | 按需 |
| 工具与脚本 | 需要调用的小程序 | 按需 |
| 版本号 | 这是第几版，改了什么 | 建议 |

**三个"必须"是下限，别省。** 一份只有十来行、但这三样齐全的手册，比一份洋洋洒洒却漏了"禁止事项"的手册好用得多。

---

## 2.3 跟"每次重新交代"有什么区别

| 对比项 | 每次口头交代 | 做成 AISkill |
| --- | --- | --- |
| 你要花的时间 | 每次都重说一遍 | 说一次，永久用 |
| 结果稳定性 | 今天一个样，明天一个样 | 基本一致 |
| 别人能不能用 | 只能你自己会 | 发给谁都能用 |
| 改起来 | 改完就忘了上次怎么说的 | 改文件，留记录 |
| 出错时 | 不知道哪句话没说清 | 翻文件就能找到漏洞 |

最后一行值得多说一句：**出错时能查。** 你口头交代完就没了，出了问题只能凭记忆回想"我当时是不是没说清楚"。写成文件，你可以逐句对着看，问题出在哪一句一目了然。

## 2.4 标准目录结构

不用背，照这个建就行：

```
AISkill/
├── README.md           ← 说明书：讲清楚这个技能是什么、怎么用（就是这类文件）
├── SKILL.md            ← 正文：真正递给 AI 看的那份操作手册
├── references/         ← 参考资料：术语表、模板、长例子
├── scripts/            ← 小工具：需要自动处理文件时放这里
└── assets/             ← 素材：图片、表格模板等
```

**新手只需要前两个。** 后面三个等真的需要了再加，不要一上来就摆一堆空文件夹。

逐个说清楚每个位置放什么：

| 位置 | 放什么 | 给谁看 | 什么时候需要 |
| --- | --- | --- | --- |
| `README.md` 或 `AISkill.md` | 简介、什么时候用、怎么用、注意事项 | 人（同事、未来的你） | 一开始就写 |
| `SKILL.md` | 步骤、禁止事项、示例 | AI | 一开始就写 |
| `references/` | 术语表、完整模板、历史案例 | AI（需要时查） | 素材太长，正文塞不下时 |
| `scripts/` | 自动处理文件的小程序 | 电脑执行 | 要批量处理几十上百个文件时 |
| `assets/` | 图片、表格模板等素材 | 两者都可能 | 有需要附带的东西时 |

> ⚠️ **注意**
> 文件名区分大小写。`SKILL.md` 和 `skill.md` 在一些系统里是两个不同的文件。统一用大写，别混。

> 💡 **你也可以像本文档一样拆得更细**
> 当一个技能要写的内容变多时，`SKILL.md` 会变得又长又难维护。这时可以按主题拆成多个文件，用一个入口文件串起来——本手册（[总入口](../README.md)）就是这么做的，可以当参考。

---

## 本篇要点

- 最小的 AISkill 就是一个文本文件，不涉及代码。
- 三样东西不能省：适用场景、步骤、禁止事项。
- 目录结构前两项必建，后三项按需再添。
- "禁止事项"是新手最容易忽略、却最影响效果的一节。
