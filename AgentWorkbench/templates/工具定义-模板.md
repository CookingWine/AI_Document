# 工具定义：____

> 新增一个 Agent 工具时复制本表填写。填不全，说明这个工具还没想清楚，先别加。

## 基本信息

| 项 | 内容 |
| --- | --- |
| 工具名 | `snake_case`，动词开头，模型看得懂 |
| 类型 | 只读 / 变更提议 |
| 一句话描述 | 会出现在模型的工具列表里，写清"做什么"和"不做什么" |
| 是否需要确认 | 只读：否 ｜ 变更：**必须** |
| 调用上限 | 每轮最多次数 |

## 返回

成功：

```json
{ "ok": true }
```

失败（必须结构化，模型要能据此自修）：

```json
{ "ok": false, "error": "", "issues": [], "hint": "" }
```
